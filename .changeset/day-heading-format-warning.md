When you install the travel setup in a vault whose existing notes write day headings in another date format, for example `## 10.05.2026` instead of `## 2026-05-10`, Trips now says so right away. Before, activities under those headings silently showed as not on a day. If the headings consistently use one format, it offers to switch the kind's day-heading format to it; if they mix formats, or a date could be read two ways, it names them instead. Notes are never changed. The day-heading format setting now previews today's full heading, for example `## 2026-11-01`.
